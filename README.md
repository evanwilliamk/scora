# Scora prototype (April-May 2026)

Archived snapshot of the early native prototype that lived only on Evan's Mac
(`~/scora/scora`) and was never committed. It is NOT the current app: the
current project is on `main` (`apps/ios` + `apps/api`).

Kept for reference: CalibrationEngine, EnergyCalculator, the HealthKit and
Strava managers, and the first Supabase edge functions (nightly-score,
strava-oauth) and schema.

The Supabase publishable key was replaced with a placeholder before pushing.
Excluded: `build/`, `supabase/.temp/` (local CLI state), Xcode user data.
